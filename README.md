# Rosix-views

Sammlung von Webseiten des IBC, veröffentlicht über GitHub Pages unter
https://hzdr-ibc.github.io/Rosix-views/

| Seite       | URL                                                  |
|-------------|------------------------------------------------------|
| Schichtplan | https://hzdr-ibc.github.io/Rosix-views/Schichtplan/    |
| GATE        | https://hzdr-ibc.github.io/Rosix-views/GATE/           |

## Neue Seite hinzufügen

1. Ordner mit dem gewünschten Namen anlegen, z. B. `NeueSeite/`.
2. Die Seite als `NeueSeite/index.html` hineinlegen.
3. In `index.html` (Übersicht) einen Link `<li><a href="NeueSeite/">NeueSeite</a></li>` ergänzen.
4. Committen und pushen – nach ca. einer Minute ist die Seite unter
   `https://hzdr-ibc.github.io/Rosix-views/NeueSeite/` erreichbar.

Hinweis: GitHub-Pages-Seiten sind öffentlich. Alles im Quelltext (z. B. Ninox-Share-Links) ist für jeden sichtbar.
